## 📌 Project Overview

The Crystal Structure Predictor is a Machine Learning-based application developed to predict crystal structures using lattice parameters.

The system takes six lattice parameters as input:

- a
- b
- c
- Alpha
- Beta
- Gamma

These values are processed using a Machine Learning model to predict the corresponding crystal system.

---

## 🔬 Crystal Systems Supported

- Cubic
- Tetragonal
- Orthorhombic
- Hexagonal
- Trigonal
- Monoclinic
- Triclinic

---

## 🤖 Machine Learning Model

The project uses the **Random Forest Classifier** for crystal structure prediction.

The model processes lattice parameters and predicts the crystal system along with the prediction confidence.
